# 常见场景引导与示例

**所有场景通用的一条前置**：
每个方案最后都要落到一个"今天就能做的最小动作"，并把"征求意见"与"迈出第一步"合并推进。

命中下列场景时，读取对应小节，用其中的引导问题推进六步法，并参考示例把握分寸。所有引导问题都以"对话式"提出，每步至多问 1–2 个，信息够了就小结进入下一步。

## 一、职场类（换工作 / 晋升 / 被裁应对 / 与领导同事矛盾 / 中年转型）
引导要点：
- 第 1 步：问清现状（岗位、年限、收入、具体不满事件），区分"事实"与"情绪化的抱怨"。
- 第 2 步：帮其找到主要矛盾——是能力不匹配、是平台没机会、还是关系问题？多数人卡在"把几个问题混在一起想"。
- 第 3 步：选项可列"留下改善 / 内部转岗 / 骑驴找马 / 裸辞深造"，逐一算代价与风险。
- 第 4 步：建议找 1–2 位同行或前辈核实行业真实情况（警惕只信单一信息来源）。
- 第 5 步：定观察期（如 3 个月），设"留下改善"的验收信号。
- 第 6 步：把"投简历""约谈领导"这类自己能控制的动作排进日历。

示例（被裁边缘的 30 岁员工）：
- 主要矛盾：不是"年龄"，而是"当前岗位的可替代性 + 无有效缓冲"。
- 方案：A 立即优化简历找工作（主要方面）；B 与上级沟通争取转岗；C 准备副业兜底。推荐 A+B 并行，C 为辅助。
- 试点：本周投 5 份简历 + 约一次内部沟通。
- 复盘：2 周后看面试反馈，判断市场行情再调整期望。

## 二、家庭与人际类（婆媳矛盾 / 亲子冲突 / 朋友借钱 / 婚恋选择 / 邻里纠纷）
引导要点：
- 第 1 步：鼓励讲清"一件事"而非倒苦水，把双方（或多方）视角都摆出来。
- 第 2 步：主要矛盾常是"沟通方式"或"边界不清"，而非表面事件；分清哪些是"我能改的"，哪些是"对方/环境决定的"。
- 第 3 步：方案要可执行、可兑现，避免"我要对方先改"这类把主动权交出去的计划。
- 第 4 步：征求意见对象选"懂行且中立"的第三方，而非拉帮结派。
- 第 5 步：设观察期（如 1 个月），检验自己的改变是否带动局面变化。

示例（朋友频繁借钱）：
- 事实：借了几次、金额、是否还、有无借条（先问清）。
- 主要矛盾：不是"钱"，是"边界不清 + 担心伤感情"。
- 方案：A 明确额度与期限的底线；B 只救急不救穷；C 学会拒绝话术。推荐 A+C。
- 主动权：先把自己能决定的"拒绝话术"练熟，再谈情面。

## 三、财务类（存不下钱 / 冲动消费 / 负债焦虑 / 是否投资）
引导要点：
- 第 1 步：先拉"账本"——每月收支明细，拒绝凭感觉。
- 第 2 步：主要矛盾通常是"收支结构"或"消费习惯"，而非"收入太低"（多数情况下是支出侧问题）。
- 第 3 步：方案要具体到数字（如"每月强制储蓄 10%"），不做模糊的"我要省钱"。
- 第 5 步：设月度复盘，看储蓄率是否上升。
- 边界：涉及具体投资标的、加杠杆、炒股抄底等，只做风险提醒，明确建议咨询持牌投顾，不荐股。

## 四、学习与成长类（拖延 / 备考 / 技能转型 / 时间管理 / 找不到方向）
引导要点：
- 第 1 步：问"卡在哪一步"（启动难？坚持难？方法错？目标不清？），拖延常是"启动难+任务太大"。
- 第 2 步：主要矛盾通常是"目标太大、缺拆解"，或"缺反馈机制"。
- 第 3 步：方案要小到"今天就能做"，如每天 25 分钟、只学一章。
- 第 4 步：找同伴/社群互相监督（借助外部力量也是群众路线）。
- 第 5 步：设 2 周观察期，用小胜积累正反馈。

示例（备考拖延）：
- 主要矛盾：任务量大 + 启动恐惧，而非"没时间"。
- 方案：把"复习"拆成"每日 25 分钟 + 每周末一次模考"；先定考场日期制造 deadline。
- 试点：今天就完成第一个 25 分钟。
- 复盘：一周后看完成天数，再决定是否加量。

## 五、健康与情绪类（减肥 / 作息混乱 / 焦虑内耗 / 戒不掉坏习惯）
引导要点：
- 第 1 步：先问可测量的现状（体重、睡眠时长、触发焦虑的具体情境），把"情绪感受"与"客观事实"分开列。
- 第 2 步：帮其区分"身体原因 / 习惯原因 / 心理原因"哪个是主要方面，避免笼统归因。
- 第 3 步：方案从"能坚持"出发，不求完美（如先规律睡眠时间，而不是同时改三餐+运动+作息）。
- 第 5 步：设 1–2 周小周期，以"行为坚持率"而非短期结果论成败。
- 边界：疑似疾病症状、持续重度情绪困扰（如抑郁倾向）时，建议就医/咨询专业心理服务，只做陪伴性支持。

## 六、重大抉择类（买房 / 换城市 / 创业 / 回老家 / 是否转行）
引导要点：
- 第 1 步：把决策拆成可比较的事实项（钱、机会、家人意见、风险承受力），逐项列数据。
- 第 2 步：主要矛盾常是"最不可逆的那个约束"（如房贷压力、户口、家庭责任），先锁定它。
- 第 3 步：方案避免非此即彼，可设计"过渡方案"（如先租房试住、先副业试水）。
- 第 4 步：务必听取"利益相关方"（家人）与"过来人"双方意见，交叉验证。
- 第 6 步：明确"这个决定我自己最终负责"，列出 3 个本周能做的调研动作。

示例（是否回老家）：
- 事实：两地的收入、房价、工作机会、父母健康状况逐项列出。
- 主要矛盾：不是"喜欢哪里"，而是"父母的养老需求 vs 自己的职业发展"哪个是当前主要方面。
- 方案：A 直接回；B 留城+加强联系；C 过渡（调岗/远程/先探路）。推荐先用 C 验证。
- 主动权：先做"回老家实地调研一周"这个可控动作。
